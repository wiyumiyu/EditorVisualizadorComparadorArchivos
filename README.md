# Práctica Programada 2: Editor, Visualizador y Comparador de Archivos en Ensamblador x86-64

Curso: Arquitectura de Computadoras (IC-3101)
Universidad: Tecnológico de Costa Rica (TEC)
Periodo: I Semestre 2024

Descripción:
Desarrollo de un editor y visualizador de archivos de texto implementado en lenguaje ensamblador x86-64 para Linux. La aplicación permite abrir, leer, visualizar, editar y comparar archivos desde consola, incluyendo funcionalidades como navegación por líneas, visualización hexadecimal y detección de diferencias entre archivos. El proyecto involucró manejo directo de archivos mediante syscalls, manipulación de buffers, conversión de datos y programación de bajo nivel enfocada en rendimiento y control del hardware.
